# Portfolio – Ayaj Uddin

A simple and modern personal portfolio website showcasing my projects, skills, and contact details.  
Built to highlight my work as a MERN Stack Web Developer.

## 🌐 Live Demo

🔗 https://ayaj-uddin.onrender.com

## ✨ Features

- Fully responsive design
- Clean and minimal UI
- Showcases my projects with external links
- Includes About Me and Skills sections
- Social and contact information included
- Fast, lightweight, and easy to navigate
